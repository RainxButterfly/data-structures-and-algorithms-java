## 📊 复杂度速查（持续更新）

| 内容                        | 时间复杂度（平均） | 空间复杂度  | 备注          |
| --------------------------- | ------------------ | ----------- | ------------- |
| 二分查找                    | O(log n)           | O(1)        | 有序区间      |
| 线性查找                    | O(n)               | O(1)        | 通用          |
| 单链表插入/删除（已知前驱） | O(1)               | O(1)        | 查找 O(n)     |
| 堆插入 / 删除               | O(log n)           | O(1) 辅助   | 优先队列      |
| 归并排序                    | O(n log n)         | O(n)        | 稳定          |
| 快速排序（平均）            | O(n log n)         | O(log n) 栈 | 不稳定        |
| BST 操作（平均）            | O(log n)           | O(h)        | 退化为链 O(n) |
